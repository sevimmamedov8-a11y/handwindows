# HandARBrowser Windows — одно окно

Отдельная Windows-версия без стерео и без двух глаз. Камера занимает фон, по центру находится одно обычное окно браузера, поверх него отображается курсор указательного пальца.

## Управление

☝ указательный палец — курсор
🤏 pinch — клик
🤏 + движение — прокрутка
⌨ — виртуальная клавиатура
CENTER — центр интерфейса

## Сборка через GitHub Actions

1. Создай новый репозиторий, например `HandARBrowser-Windows`.
2. Загрузи содержимое этого проекта через GitHub Desktop.
3. Сделай Commit и Push.
4. Открой Actions → `Build HandARBrowser Windows EXE`.
5. После зелёной галочки открой Artifacts → `HandARBrowser-Windows-EXE`.

## Важно

Модуль распознавания рук загружается из MediaPipe при первом включении Hand tracking. Для первого запуска нужен интернет.

На ПК нет гироскопа телефона, поэтому эта версия не делает настоящий 3DoF head tracking как iPhone-версия. Она предназначена как одноэкранный desktop-вариант с камерой, браузером и управлением рукой.

Electron и electron-builder используются для упаковки Windows EXE; MediaPipe Tasks Vision предоставляет Hand Landmarker для распознавания руки. Версии зафиксированы в `package.json`.
